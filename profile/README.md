## Overview

VS Code Cross Platform is a lightweight code editor concept built around a consistent development experience across operating systems. It brings together Windows, macOS, and Linux support with remote development capabilities into a single workbench that adapts to different environments.

---

## Essential Cross-Platform Features

- **Multi-Platform Support:** Run on Windows 10 and 11 (64-bit), macOS versions with Apple security update support, and supported Linux distributions including Ubuntu, Debian, RHEL, and Fedora.
- **Consistent Workbench:** Access files, code intelligence, terminal, source control, debugger, and tests from the same window regardless of platform.
- **Remote Development:** Develop on a local computer, connect to a remote machine or container, or make lightweight changes with VS Code for the Web.
- **Extension Ecosystem:** Install extensions to add rich support for almost any programming language, framework, or service.
- **Customizable Environment:** Customize layout, keyboard shortcuts, and behavior, then use profiles to switch between configurations for different projects.
- **Lightweight Footprint:** Small download size and minimal disk footprint suitable for most available hardware.

---

## What VS Code Cross Platform Brings to Development Workflows

The editor provides a unified environment that does not prescribe a programming language, operating system, or set of development tools. Instead, it adapts to the project and the tools already in use.

Platform coverage spans the major desktop operating systems. Windows 10 and 11 are supported in 64-bit versions, macOS versions with Apple security update support are covered, and Linux distributions including Ubuntu Desktop, Debian, RHEL, and Fedora are supported.

Remote development extends the concept beyond local machines. The editor can connect to remote machines, containers, or WSL environments, allowing development to happen where the code actually runs.

The extension ecosystem keeps the editor flexible. Language support, debuggers, and tooling for frameworks are added through extensions rather than being built into the core.

Customization supports different workflows. Profiles allow switching between configurations for different projects or tasks, and the layout and keyboard shortcuts can be adjusted to personal preference.

The editor follows a monthly release cadence. Stable builds ship each month with new features and bug fixes, and auto-update is supported on most platforms.
